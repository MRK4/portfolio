## The Challenge

Build and ship a fully functional product in a single day — no shortcuts on quality, just constraints on scope.

**ToDoGether** is the result: a clean, collaborative todo list where tasks are persisted in a database and accessible across sessions.

## What it Does

- Create and manage todo lists
- Mark tasks as complete
- Persistent storage via **Prisma** and a serverless database

## Takeaways

Shipping in one day forces ruthless prioritisation. Every feature decision was filtered through a single question: *does this make the core loop better?* The result is a product that does exactly one thing well.
