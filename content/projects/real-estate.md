## The Origin Story

Every developer has a first project. This is mine.

Built to learn **React** from zero, the real estate app is a property listing interface — browse listings, filter by criteria, view details. Simple by design, meaningful in what it unlocked.

## What it Does

- Property listing grid with filtering
- Individual property detail pages
- Responsive layout with **Tailwind CSS**

## Looking Back

The code is not the point. The point is that this project proved the loop: build something real, ship it, learn from it. Everything since has followed that same pattern.
