## The Brief

Design and develop a professional web presence for **Farmanip**, an automotive company. The goal was a clean, credible site that communicates the company's services and expertise.

## Approach

Built on **WordPress** with **Advanced Custom Fields Pro** for flexible content management, allowing the client to update content autonomously without touching code.

The design was prototyped in **Figma** before implementation, ensuring alignment with the client's visual identity before a single line of code was written.

## Delivery

- Custom WordPress theme
- ACF-powered page builder blocks
- Responsive design across all breakpoints
- Client training for autonomous content updates
